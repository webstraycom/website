## Overview

The User Guide provides practical instructions for operating WebStray Authenticator. It covers the end-to-end workflow, from initial vault initialization to advanced data management and plugin configuration.

While the [Developer Guide](/docs/authenticator/developer-guide) focuses on codebase and extensibility, this section is dedicated to interface interactions and daily usage. It provides the necessary steps to manage your secrets effectively within the application.

## Reading Order

To begin using WebStray Authenticator, it is recommended to follow this sequence:

1. [Getting Started](/docs/authenticator/user-guide/getting-started) – Installation, vault setup, and security basics.
2. [Authentication](/docs/authenticator/user-guide/authentication) – Vault unlock, identity verification, and session behavior.
3. [Passwords](/docs/authenticator/user-guide/passwords) – Management of login credentials.
4. [TOTP](/docs/authenticator/user-guide/totp) – Management of time-based one-time passwords.
5. [Tokens](/docs/authenticator/user-guide/tokens) – Management of API keys and access tokens.
6. [Import & Export](/docs/authenticator/user-guide/import-and-export) – JSON exports, password-protected payloads, and data portability.
7. [Settings](/docs/authenticator/user-guide/settings) – Visual preferences, security policies, and vault maintenance.
8. [Plugins](/docs/authenticator/user-guide/plugins) – Adding, management, and security.
9. [FAQ and Troubleshooting](/docs/authenticator/user-guide/faq-and-troubleshooting) – Common issues and their solutions.

## Summary

WebStray Authenticator combines local-first convenience with robust encryption. By following these guidelines, you can ensure that your credentials remain organized, accessible, and protected by industry-standard security practices.
